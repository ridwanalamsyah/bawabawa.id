# KPI mingguan

Isi setiap Senin (spreadsheet sederhana cukup). Sumber data: **Admin →
Laporan**, **Pesanan masuk**, Plausible.

| KPI | Cara hitung | Target awal |
|-----|-------------|-------------|
| Request masuk | jumlah pesanan baru | naik tiap minggu |
| Konversi penawaran | disetujui ÷ penawaran dikirim | ≥ 60% |
| Waktu respon | rata-rata submitted → quoted | < 2 jam kerja |
| Order dibayar | jumlah `paid` | — |
| GMV | total nilai barang dibayar | — |
| Pendapatan jasa | jasa + margin ongkir | — |
| Isi kargo | kg terpakai ÷ kapasitas per trip | ≥ 80% |
| Repeat order | customer dengan ≥ 2 order ÷ semua customer | ≥ 30% setelah 3 bulan |
| Komplain | komplain ÷ order terkirim | < 3% |
| Rating | rata-rata ulasan | ≥ 4,5 |
| Funnel situs | `request_start` → `request_submit` | ≥ 25% |

Kalau satu angka turun dua minggu berturut-turut, pilih satu perbaikan
untuk minggu berikutnya (bukan lima).
