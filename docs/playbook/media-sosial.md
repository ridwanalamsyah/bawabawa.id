# Media sosial

Jastip dijual lewat kepercayaan dan bukti. Konten terbaik adalah proses
nyata: toko, nota, timbangan, paket sampai.

## Kanal

| Kanal | Fungsi | Frekuensi |
|-------|--------|-----------|
| **Instagram** | Katalog visual, story proses belanja, highlight "Testimoni", "Cara order", "Open Trip" | Feed 3×/minggu, story harian saat belanja |
| **TikTok** | Jangkauan: live belanja dari toko, "haul" titipan, unboxing customer | 3–5 video/minggu, live 1–2× saat PO buka |
| **WhatsApp Channel** | Pengumuman PO, jadwal trip, promo | Mengikuti [PO batch](po-batch.md) |
| **WA Business** | Chat order, katalog WA, label status pelanggan | Harian |
| **Google Business Profile** | Muncul di pencarian "jastip Bandung Samarinda", ulasan Google | Update foto mingguan |

Bio semua kanal mengarah ke `bawabawa.id/request` (atau `/katalog` kalau
sedang ada stok siap).

## Pilar konten

1. **Bukti** — foto nota, timbangan, paket berangkat/sampai, ulasan customer.
2. **Belanja bareng** — live dari toko, "titipan minggu ini".
3. **Edukasi** — cara order, beda Reguler/Kargo/Kilat, hitung ongkir.
4. **Produk Bandung** — barang yang susah dicari di Samarinda.
5. **Behind the scenes** — tim, packing, perjalanan kargo.

## Kreator lokal

- Ajak 3–5 kreator Samarinda (micro, 5k–50k followers) lewat program
  [afiliasi](reseller.md): komisi per order dengan kode referral.
- Beri mereka satu titipan gratis/ongkir gratis untuk konten pertama.

## Ukur

- Pasang `NEXT_PUBLIC_PLAUSIBLE_DOMAIN` → lihat event `request_start`,
  `request_submit`, `checkout_submit`, `whatsapp_click` per sumber.
- Pakai UTM di link bio (`?utm_source=instagram`) supaya kanal bisa
  dibandingkan.
